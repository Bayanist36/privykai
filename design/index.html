Спокойствие и ясность вместо геймификации и давления.

Палитра

Тёплая бумага #FAF8F3, глубокий зелёный #2A7052, янтарный акцент для серий. Контраст текста — не ниже AA.

Типографика

Сегодня

Inter (OFL), кириллица + латиница. Шкала 40 / 28 / 20 / 17 / 16 / 14 / 13 / 12. Заголовки 700, основной текст 400, служебный 500.

Тон

  • Поддерживаем, а не стыдим: «Серия начнётся сегодня» вместо «Вы всё пропустили».
  • Один экран — один ответ. Никаких лишних настроек в MVP.
  • Данные принадлежат пользователю: офлайн по умолчанию.
