## Главное из аудита

**4 блокера:**

1. **S-01** — ошибка чтения привычек на «Сегодня» выглядит как пустое состояние
   «Пока нет привычек», кнопки «Повторить» нет.
2. **ST-01** — на «Статистике» ошибка чтения не показывается вообще: пустой
   экран с CTA. Риск: пользователь думает, что данные пропали.
3. **S-05** — подписи на зелёной карточке прогресса используют белый 72 %
   (3,94:1 светлая, 3,92:1 тёмная). Нужно 88 % (5,02:1 / 5,30:1).
4. **D-01** — действие «Отменить» в тёмном снекбаре: #8CC6A8 на #E8EFE9 = 1,67:1.
   Нужен #1F5C43 (6,72:1).

**Важное, что стоит сделать до 1.1:** D-02 (тот же 72 % в тёмной), D-04
(границы 1,31–1,76:1), Inter не встроен (pubspec fonts закомментирован, app bar
просит Roboto); радиус кнопки 12 вместо 16; нижняя навигация ~56 вместо 76;
поле ввода с границей 1,26:1; тач-таргеты цвета 36 dp и дня 40 dp; подзаголовок
настроек «Одно уведомление в день» противоречит интервальным напоминаниям.
Полный список — в UI-аудите (21 «важно», 20 «мелочь»).

## Виджет

- Размеры: **2×1 = 152×72 dp** (PNG 456×216 @3x), **4×2 = 328×160 dp** (PNG 984×480 @3x).
- 3 варианта на размер, 4 состояния (пусто / активно / выполнено / серия),
  светлая и тёмная тема.
- Рекомендуемый вариант — **A**: 2×1 с кольцом, 4×2 со списком привычек.
- Тап по любой точке открывает «Сегодня»; отметки из виджета нет осознанно.
- Данные: текущие четыре ключа моста + аддитивные `widget_date`,
  `widget_state`, `widget_items_json`, `widget_top_name`, `widget_top_streak`.
  Без `widget_items_json` 4×2 работает в fallback-режиме (одна строка).
- Обновление: после загрузки/отметки/редактирования/удаления/сброса, при
  возврате из фона, по broadcast смены даты/времени/пояса. `updatePeriodMillis = 0`.
- Устаревание: если дата снимка не сегодня — «Новый день / Откройте приложение»,
  а не вчерашние «4 из 4».

## Концепты v1.2

1. **Статистика** — переключатель 7/30, тренд по дням, хитмап 12 недель,
   блок «Цели недели». Два PNG: верх экрана и прокрутка.
2. **Тихие часы** — отдельный экран из «Настроек», глобальный фильтр 22:00–08:00.
   Интервальную карточку v1.1 не переделывал: в форме только информационная
   строка, все настройки — на отдельном экране.
3. **Цель «3 раза в неделю»** — третий режим повторения, недельная серия,
   отдельный блок «Цели недели» в «Сегодня». **Требует подтверждения модели
   данных** у DeepSeek Agent и разработчика.
4. **Первый запуск** — 2 шага вместо 3 слайдов; на втором выбор первой привычки
   с предзаполненной формой, чтобы обещание «добавим вместе» выполнялось.

## Открытые решения (не блокируют сдачу дизайна)

2. **Тихие часы:** подтвердить глобальность и дефолт «включено, 22:00–08:00»
   для существующих установок.
3. **Виджет:** подтвердить, что 4×2 со списком — цель v1.1.1, а в первом релизе
   допустим fallback без `widget_items_json`.
