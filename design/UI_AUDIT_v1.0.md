# UI-аудит v1.0 — «Привыкай», версия 1.1

**Задача:** SUK-22
**Дата:** 3 ноября 2026
**Автор:** Дизайнер
**Объект:** экраны Flutter-приложения, макеты `design/`, PNG-экспорт `design/exports/`,
кадры `design/store/app/` и скриншоты RuStore.
**Метод:** сверка исходников экранов и текущих макетов, расчёт контраста по WCAG 2.1
(`design/tools/contrast.mjs`), проверка геометрии по коду. Код в `lib/` не изменялся.

## 8. Что делать в первую очередь

1. **S-01 + ST-01 + ON-05** — одно состояние `loadFailed` с retry на трёх экранах. Это ложное «данных нет» и риск повторного онбординга.
2. **S-05 + D-01 + D-02** — 88 % для текста на акценте и зелёный `snackAction` в тёмной теме. Это дешево и снимает два блокера доступности.
3. **F-01 + F-02 + D-04** — границы полей/чеков и тач-таргеты 48 dp. Без этого форма не проходит WCAG.
4. **G-01 + G-02 + G-03** — Inter, радиусы, таб-бар. Приводит приложение к макету без переделки экранов.
5. **SET-01 + ON-01** — ложь в текстах: «одно уведомление в день» и «добавим вместе». Правится копирайтом.

Остальные пункты — в 1.1.1 или вместе с концептами 1.2. Концепты и предлагаемые токены:
`design/V1_2_CONCEPTS.md`, `design/TOKENS_AUDIT_v1.0.md`,
`design/tokens/tokens-v1.2-proposed.json`.
