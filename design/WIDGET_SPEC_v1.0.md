# Спецификация виджета «Сегодня» — v1.1

**Задача:** SUK-22 · **Дата:** 3 ноября 2026 · **Автор:** Дизайнер
**Платформа:** Android, `home_widget` + `RemoteViews` (без Flutter-рендера в виджете)
**Файлы макетов:** `design/widgets/widget-2x1.html`, `design/widgets/widget-4x2.html`
**PNG:** `design/widgets/exports/`

## 1. Рамки и принципы

Виджет — **только чтение и вход в приложение**. Отметка привычки из виджета не
делается: это требует фонового состояния, конфликтует с оптимистичной отметкой в
приложении и ломает офлайн-модель. Один тап по любой точке виджета открывает
«Сегодня».

Принципы те же, что у приложения: тихий прогресс, тёплая бумага и глубокий
зелёный, никаких красных «провалов», конфетти и вымышленных функций.

## 2. Размеры и сетка

| Формат | Целевой размер | @3x PNG | `minWidth` / `minHeight` | Углы | Поля |
|---|---|---|---|---|---|
| 2×1 | **152 × 72 dp** | 456 × 216 | 110 × 40 dp | 20 dp | 12 × 10 dp |
| 4×2 | **328 × 160 dp** | 984 × 480 | 250 × 110 dp | 24 dp | 16 × 14 dp |

- `targetCellWidth` / `targetCellHeight`: 2×1 и 4×2 (Android 12+).
- `resizeMode="horizontal|vertical"`; контент не «прыгает»: при растяжении
  увеличиваются только внешние поля, внутренняя сетка остаётся 4 dp.
- Безопасная зона: 8 dp по краям для 2×1, 12 dp для 4×2. Лаунчеры отличаются:
  проверять на 140–180 × 64–84 dp (2×1) и 300–360 × 150–180 dp (4×2).
- Никакого текста меньше 9 sp; при системном масштабе 1,3 проверять 4×2
  (строки списка получают `maxLines=1`, `ellipsize=end`).

## 3. Три варианта

### 3.1 2×1

| Вариант | Композиция | Когда использовать |
|---|---|---|
| **A — кольцо** (рекомендуется) | Слева «СЕГОДНЯ» + «2 из 4» + «Осталось 2»; справа кольцо 40 dp с 50 % | Лучший баланс: прогресс и остаток считываются за 0,5 с |
| B — полоса | Сверху «Сегодня» и «2 из 4», снизу 4 сегмента и полоса | Если нужен максимально спокойный вид без кольца |
| C — крупная дробь | «2/4» крупно + 4 сегмента справа | Для тех, кто считает «сколько сделано», а не «сколько осталось» |

### 3.2 4×2

| Вариант | Композиция | Когда использовать |
|---|---|---|
| **A — список** (рекомендуется) | Заголовок «Сегодня» + «2 из 4», полоса, 2 привычки (галочки), футер «Осталось 2 / серия 12» | Основной: видно, что именно осталось |
| B — кольцо + список | Кольцо 64 dp слева, 3 строки справа | Если важнее прогресс, чем список |
| C — неделя | «Эта неделя · 5 из 7», 7 точек по дням, «Лучшая серия 12» | Для тех, кто смотрит на неделю, а не на день |

**Рекомендация:** A для обоих размеров. B/C — альтернативы, не включать в первый
релиз виджета, если разработчик ограничен по времени.

## 4. Состояния

Состояние выбирается по данным в таком приоритете:

1. **Пусто** — `total == 0`.
2. **Выполнено** — `completed == total` и `total > 0`.
3. **Серия** — не всё выполнено, но у любой привычки `currentStreak >= 7`.
4. **Активно** — во всех остальных случаях.

| Состояние | 2×1 (A) | 4×2 (A) |
|---|---|---|
| Пусто | «СЕГОДНЯ» / «Пусто» / «Добавьте первую», кольцо с «+» | «Сегодня · 0 из 0», иконка листа, «Нет привычек» / «Добавьте первую в приложении» |
| Активно | «2 из 4» / «Осталось 2», кольцо 50 % | «2 из 4», полоса 50 %, две строки: «Вода ✓ 12 дней», «Чтение ○ 4 дня», футер «Осталось 2 · 12 дней» |
| Выполнено | «4 из 4» / «Всё выполнено», кольцо 100 % с галочкой; фон `green50` | «Готово · 4 из 4», 100 %, все строки с галочками, футер «Всё выполнено · Серия 12» |
| Серия | Бейдж пламени, «Вода», «12 дней подряд», галочка | «Серия · лучшая 28», пламя 48 dp, «12 дней подряд», «Вода · сегодня отмечена», футер «Лучшая серия — 28 дней» |

**Серия — не отдельный экран данных, а режим подачи.** Если серия есть, но день
ещё не закрыт, 2×1 показывает её вместо счётчика; 4×2 оставляет список и выносит
серию в футер. Если всё выполнено, «Выполнено» важнее серии, но серия остаётся в
футере.

**Пусто ≠ ошибка.** Если данных нет из-за ошибки чтения, виджет не должен писать
«Нет привычек». Провайдер получает `widget_state = empty|active|done|streak|stale`
и при `stale` показывает «Откройте приложение», а не нули.

## 5. Тема

Цвета — Android-ресурсы `values/colors.xml` + `values-night/colors.xml`; виджет
сам переключается при смене темы системы, без перезапуска приложения.

| Роль | Светлая | Тёмная | Где |
|---|---|---|---|
| Фон | `#FFFFFF` | `#1A211C` | корень |
| Фон «выполнено» | `#EDF4EF` | `#1E2F26` | корень в done |
| Основной текст | `#18201B` | `#EDF2EE` | счётчик, имена |
| Вторичный текст | `#6B756D` | `#A9B3AC` | подписи, «осталось» |
| Акцент | `#2A7052` | `#58A985` | кольцо, полоса, галочка |
| Текст на акценте | `#FFFFFF` | `#0D1A13` | галочка в заливке |
| Трек | `#EAE5DA` | `#2C362E` | кольцо/полоса |
| Граница контрола | `#948C7C` | `#5E7164` | пустая галочка 18 dp (3:1) |
| Пламя/серия | `#B87120` иконка, `#8A4F13` текст | `#E0A354` | бейдж, футер |
| Фон серии | `#F8E9D2` | `#3A2A16` | бейдж 2×1 |

Правила:
- Никаких градиентов и стоковых картинок.
- Текст не кладём прямо на обои: у виджета всегда своя поверхность.
- Контраст: вторичный текст ≥4,5:1, счётчик ≥7:1, пустая галочка ≥3:1.
- Цвет привычки в виджете не используется как фон плитки: в тёмной теме это
  создаёт светлые пятна. Плитка 22 dp нейтральная; эмодзи — из привычки.

## 7. Контент и тексты

Короткие, без восклицаний:

- `progressLabel`: «2 из 4»; `0 из 0` только в пустом состоянии.
- `pendingLabel`: «Осталось 2», «Осталось 1», «Всё выполнено», «Добавьте первую».
- Имена привычек — до 16 символов в строке, затем `…`; полное имя доступно в
  приложении.
- Серия: «12 дней подряд»; 1 — «1 день подряд»; 0 — не показывать.
- Пусто: «Пусто» / «Добавьте первую» (2×1), «Нет привычек» / «Добавьте первую в
  приложении» (4×2).
- Устарело: «Новый день» / «Откройте приложение».

## 8. Поведение по тапу

- Тап по любой точке виджета → `PendingIntent` на `MainActivity` с action
  `OPEN_TODAY` (открыть вкладку «Сегодня», не форму).
- Отдельных тап-зон по привычкам нет: 18–22 dp галочка — плохая цель, а перенос
  отметки в виджет требует фоновой записи.
- Долгое нажатие — системное меню лаунчера (изменение размера, удаление).
- `contentDescription` корня: «Сегодня, выполнено 2 из 4, осталось 2. Открыть
  приложение». Для пустого: «Сегодня, привычек нет. Открыть приложение».
- Декоративные эмодзи/иконки — `importantForAccessibility="no"`.
- Виджет не открывает диалоги, не запрашивает разрешения, не показывает снекбары.

## 9. Данные и обновление

### 9.1 Контракт (аддитивно к текущему мосту)

Сейчас `HomeWidgetBridge` пишет четыре ключа:
`widget_completed`, `widget_total`, `widget_progress`, `widget_pending`
(`lib/features/widget/data/home_widget_bridge_impl.dart:15-31`). Их достаточно
для 2×1 A и для fallback 4×2 A.

Для полного 4×2 A добавляются необязательные ключи:

| Ключ | Тип | Пример | Назначение |
|---|---|---|---|
| `widget_date` | String | `2026-11-03` | Проверка устаревания на границе суток |
| `widget_state` | String | `active` | `empty/active/done/streak/stale` |
| `widget_items_json` | String | `[{"name":"Вода","done":true,"streak":12,"emoji":"💧"}]` | До 3 строк, порядок отображения |
| `widget_top_name` | String | `Вода` | Герой серии |
| `widget_top_streak` | int | `12` | Герой серии |

Fallback без `widget_items_json`: 4×2 A показывает заголовок, полосу и одну
строку `pendingLabel` («Вода · Чтение · Зарядка»), без индивидуальных галочек.
Это допустимо для первого релиза; макет — целевое состояние v1.1.1.

### 9.2 Когда обновлять

- после загрузки списка, отметки/снятия, создания, редактирования, удаления,
  сброса данных;
- при возврате приложения из фона (`resumed`) — на случай смены даты;
- при смене системной темы ресурсы переключаются сами, push не нужен;
- при смене даты/времени/часового пояса — receiver на
  `ACTION_DATE_CHANGED`, `ACTION_TIME_CHANGED`, `ACTION_TIMEZONE_CHANGED`
  перерисовывает виджет из сохранённых данных;
- `updatePeriodMillis = 0`: никакого фонового опроса, только push.

### 9.3 Устаревание

Если `widget_date != today`:
- 2×1: «Новый день» / «Откройте приложение»; кольцо 0, без «выполнено».
- 4×2: «Откройте приложение» / «Данные обновятся при запуске»; список скрыт.
- Не показывать вчерашние «4 из 4» как сегодняшние.
- После открытия приложения и загрузки — обычное состояние.

### 9.4 Ошибки

Провайдер не падает и не показывает пустое состояние при ошибке записи/чтения.
Оставляет последний валидный снимок; если его нет — «Откройте приложение».
Никаких тостов и логов с персональными данными.

## 10. Реализация в RemoteViews

- `res/layout/widget_habit_2x1.xml`, `widget_habit_4x2.xml`; корень
  `LinearLayout`/`FrameLayout` с `android:clipToOutline="true"` и background
  drawable с радиусом 20/24 dp.
- 2×1 A: `TextView` ×3 + `ProgressBar` (circular) 40 dp или `ImageView` с
  послойным drawable. В `RemoteViews` допустимы `ProgressBar`, `TextView`,
  `ImageView`, `LinearLayout`, `FrameLayout`.
- 4×2 список: `LinearLayout` + `RemoteViews.addView` (до 3 строк). Не
  использовать `RecyclerView`/`ListView` без `RemoteViewsService`.
- Эмодзи — `TextView` 12 sp; не рисовать иконки привычек вручную.
- Высота строк 22–25 dp, чтобы 2 строки + футер помещались в 160 dp.
- Тени: `android:elevation` 4 dp; на Android 12+ системная обрезка может
  добавить свою — проверить, что нет двойной рамки.
- `android:padding` = 12/10 (2×1), 16/14 (4×2); `layout_margin` не использовать
  для внешнего вида, только padding.
- `minResizeWidth/Height` = 110/40 и 250/110; `maxResize` не ограничивать.
- `previewLayout` для галереи виджетов: 2×1 A в светлой теме.
- `description` в `appwidget-provider`: «Прогресс привычек на сегодня».

## 11. Доступность

- Весь виджет — одна цель; минимальная площадь 48 dp гарантирована размером.
- TalkBack: одно осмысленное описание, без перечисления декоративных элементов.
- Не полагаться только на цвет: выполнено = заливка + галочка + текст; серия =
  пламя + число.
- При системном масштабе 1,3: счётчик и заголовок не обрезаются, имя — одна
  строка с `…`, мета может скрываться.
- В тёмной теме — контраст по таблице §5; не использовать `textTertiary` для
  смыслового текста.
- Нет мигания/анимации; виджет статичен.
