# Архитектура приложения (SUK-5 → SUK-9)

Документ фиксирует решения, принятые при создании каркаса и развитии фич.
Разделы 9–10 описывают изменения задач SUK-8 и SUK-9; базовые решения SUK-5
остаются в силе.

## 1. Стек и границы

- Flutter 3.47.7 / Dart 3.13.5, только Android (`minSdk 24`, `targetSdk 36`).
- Состояние: `provider` + `ChangeNotifier`. Для текущего объёма этого
  достаточно; Riverpod/Bloc добавлять без необходимости не стали.
- Хранилище: Hive 2.2.3 (`hive_flutter`). Бэкенда, сети и авторизации нет.
- Локализация: русская, `flutter_localizations` + `intl`. Материальные
  диалоги (выбор времени) сразу на русском.
- Application ID: `com.sukhanovlabs.habittracker`. Менять нельзя: смена
  создаёт новое приложение в RuStore/Google Play.

## 2. Слои и поток данных

```text
Widget / Screen
      │ context.watch / context.read
      ▼
HabitListController (ChangeNotifier)
      │ HabitRepository (интерфейс)
      ▼
HabitRepositoryImpl
      │ HabitLocalDataSource
      ▼
Hive Box<Habit> ── HabitAdapter (typeId 13) ── Habit (domain)
```

Правила:

1. `domain` не импортирует Flutter, Hive и provider. Модель `Habit` — чистая
   immutable-сущность.
2. `presentation` не обращается к Hive напрямую, только к контроллеру.
3. `data` знает про Hive, но не про UI.
4. Новые фичи кладутся в `lib/features/<feature>/{domain,data,presentation}`;
   общее — в `lib/core`, конфигурация приложения — в `lib/app`.

Такое разделение позволяет заменить Hive (например, на SQLite для сложной
статистики) без изменения экранов: достаточно новой реализации
`HabitRepository`.

## 3. Модель и хранилище

`Habit`:

| Поле | Тип | Назначение |
| --- | --- | --- |
| `id` | `String` | UUID v4, ключ документа Hive |
| `name` | `String` | Название, до 40 символов |
| `iconKey` | `String` | Стабильный ключ эмодзи (`water`, `reading`, …) |
| `colorKey` | `String` | Ключ цвета из шести (`green`, `blue`, …) |
| `weekdaysMask` | `int` | Пн = `1 << 0` … Вс = `1 << 6`; `0x7F` — каждый день |
| `reminderMinutes` | `int?` | Минуты от полуночи; `null` — без напоминания |
| `createdAt` | `DateTime` | Порядок отображения и граница расписания |
| `completedDates` | `List<String>` | Дни выполнения `yyyy-MM-dd` |

Решения:

- **Почему Hive, а не SQLite.** На MVP нужны простые CRUD и серии; Hive даёт
  офлайн-хранилище без SQL, миграций и плагинов. Когда появятся агрегаты по
  месяцам/годам, можно перейти на `drift`/`sqflite` за интерфейсом
  репозитория.
- **Почему ручной адаптер.** Нет `build_runner`/`hive_generator`, значит
  чистое воспроизведение сборки без кодогенерации. `typeId` привычек = **13**,
  настроек = **14**: диапазон 0–12 в Hive занят встроенными
  `FrameValueType`, и адаптер в нём читался как встроенный тип (BUG-01,
  BUG-04). Новые адаптеры получают номера ≥ 15.
- **Формат дат.** Календарный день, а не timestamp: серия не зависит от
  времени отметки и перехода на летнее время. Часовой пояс — локальный.
- **Серия.** Считается от сегодня назад только по **запланированным** дням;
  незапланированные дни пропускаются и не обрывают серию. Если сегодня
  запланировано и ещё не отмечено, серия не обнуляется до конца дня. Это
  соответствует макету «Серия начнётся сегодня».
- **Дата создания.** `isScheduledOn` возвращает `false` для дней раньше
  `createdAt`, поэтому новая привычка не попадает в прошлые дни и статистику.
- **Миграция.** Адаптер typeId 13 дописан полями 6 (`colorKey`) и 7
  (`weekdaysMask`). Документы SUK-5 читаются с дефолтами `green` и «каждый
  день»; `completedDates` и время напоминания не перезаписываются.
  Счётчик полей в `read` читается один раз: повторное чтение в условии цикла
  съедало байты и обнуляло карту после `close()`/`openBox()`.
- **Настройки.** Отдельный box `settings`, один документ `app` (typeId 14):
  тема, глобальный переключатель напоминаний, время по умолчанию, флаг
  онбординга. Если box пуст, а привычки уже есть, флаг онбординга считается
  `true` — обновление не показывает слайды существующим пользователям.
- **Напоминания.** `reminderMinutes` — время, `weekdaysMask` — дни. Планировщик
  (`ReminderScheduler`) получает список привычек после загрузки и после каждой
  мутации. Одно уведомление создаётся на каждый выбранный день недели; при
  редактировании расписание пересоздаётся целиком.

## 4. Состояние

`HabitListController` отвечает за:

- загрузку списка и флаги `isLoading` / `errorMessage`;
- добавление, редактирование, переключение отметки, удаление и восстановление
  (undo), полный сброс;
- `todayHabits` и производные значения прогресса только по привычкам,
  запланированным на сегодня;
- сохранение `id`, `createdAt` и `completedDates` при редактировании.

`SettingsController` хранит тему, напоминания, время по умолчанию и флаг
онбординга, сохраняет изменения сразу и откатывает значение при ошибке записи.

Ошибки записи не теряют состояние: контроллер оставляет прежний список и
показывает баннер. Все операции идемпотентны по `id`. Контроллер защищён от
`notifyListeners()` после `dispose`.

## 5. UI и дизайн-система

- Базовые токены — `lib/app/theme/app_colors.dart` и `app_spacing.dart`.
  `AppPalette` (`lib/app/app_palette.dart`) — `ThemeExtension` с полным набором
  цветов для светлой и тёмной темы; виджеты читают `context.palette`, поэтому
  переключение темы не требует ручной замены констант.
- `AppTheme.light` / `AppTheme.dark` строят `ColorScheme` и текстовые стили из
  палитры. Тёмная палитра выведена из бренда с контрастом текста WCAG AA.
- Базовая типографика и радиусы совпадают с макетами; Material 3.
- Экраны «Сегодня» и «Новая привычка» повторяют `design/mockups/02-habits.html`
  и `03-add-habit.html`, включая пустое состояние и нижний лист действий.
- Иконки привычек — эмодзи из SUK-4 (16 значений), сопоставлены со стабильными
  ключами; компактные карточки статистики используют те же эмодзи.
- Inter пока не подключён: в `design/assets` только WOFF2, а Flutter требует
  TTF/OTF. Используется системный Roboto. Нужен TTF от дизайнера.

## 9. SUK-8: что изменилось

- `Habit` получил `colorKey` и `weekdaysMask`; серия и «Сегодня» считаются по
  расписанию, отметки прошлых дней сохраняются при редактировании.
- Форма объединена для создания и редактирования: эмодзи (16), цвет (6),
  дни недели, напоминание, защита от выхода без сохранения.
- «Сегодня» фильтрует привычки по дню недели и дате создания, показывает
  прогресс только по запланированным и поясняет, что остальные — в другие дни.
- Онбординг из трёх слайдов показывается только новым пользователям; флаг
  хранится в настройках.
- Настройки: тема (системная/светлая/тёмная), напоминания (на тот момент
  заглушка, планировщик подключён в SUK-9), время по умолчанию, сброс с двумя
  диалогами, «О приложении» и локальная политика.
- Тема реализована через `AppPalette`; все новые экраны используют
  `context.palette` и работают в обеих темах.
- Вкладка «Статистика» на тот момент была временной заглушкой; заменена в
  SUK-9.

## 10. SUK-9: напоминания и статистика

### 10.1 Напоминания

```text
HabitFormScreen ── ReminderScheduler (Provider)
                        │
HabitListController ────┤ syncAll(habits, enabled)
                        ▼
FlutterLocalReminderScheduler
  │ flutter_local_notifications + timezone + flutter_timezone
  ▼
AlarmManager (inexactAllowWhileIdle) ── ScheduledNotificationReceiver
                                      └─ BootReceiver (после перезагрузки)
```

- `ReminderPlan` — чистая математика без платформы: индексы дней недели,
  детерминированный id (`FNV-1a`, не зависит от hash seed), следующее
  срабатывание и полный план «одно уведомление на выбранный день».
- `FlutterLocalReminderScheduler` планирует `zonedSchedule` с
  `DateTimeComponents.dayOfWeekAndTime` и `inexactAllowWhileIdle` (±15 минут).
  `SCHEDULE_EXACT_ALARM` не запрашивается.
- Канал `habit_reminders` создаётся один раз: importance default, системный
  звук. Заголовок — название привычки, текст — «Отметьте привычку, когда будет
  удобно.», тап открывает приложение на «Сегодня».
- Разрешения: на Android 13+ сначала показывается объяснение, затем системный
  запрос `POST_NOTIFICATIONS`. При отказе привычка сохраняется без напоминания,
  в форме остаётся подсказка с кнопкой «Открыть настройки».
- `RECEIVE_BOOT_COMPLETED` и `ScheduledNotificationBootReceiver` возвращают
  расписание после перезагрузки/обновления приложения. При старте и возврате
  из фона `syncAll` пересоздаёт расписание (в том числе после смены часового
  пояса).
- Глобальный переключатель напоминаний в настройках передаётся в
  `syncAll(enabled:)`: выключение отменяет все уведомления, не удаляя времена
  привычек.
- Ошибки планировщика не откатывают сохранение привычки: контроллер пишет
  данные, затем пытается пересоздать расписание, ошибка только логируется.

### 10.2 Статистика

- `HabitStatistics` — чистые функции над `Habit.completedDates` и расписанием.
  Сводка 7 дней: сумма выполненных запланированных слотов / сумма всех
  запланированных слотов, включая сегодняшние невыполненные. Процент привычки
  — то же за 30 дней, но не раньше `createdAt`.
- Серии считаются только по запланированным дням: `currentStreak` от сегодня
  (или последнего запланированного дня), `bestStreak` — максимум по истории.
- Экран повторяет `design/mockups/04-stats.html`: карточка сводки, секция
  «По привычкам» с «30 дней», карточки с процентом и «Серия X · лучшая Y».
  Пустые состояния: нет привычек — CTA; есть привычки без отметок — нули и
  подсказка. Графиков и хитмапов нет (по SUK-4).
- Экран читает тот же `HabitListController`, что и «Сегодня», поэтому данные
  приходят из Hive и обновляются после любой отметки без отдельного запроса.

## 11. SUK-13: исправления QA и RC

- Hive-адаптеры переведены на typeId **13** (привычки) и **14** (настройки);
  исправлено повторное чтение счётчика полей в `read`. Добавлены регрессия
  переоткрытия бокса и тест-страж диапазона.
- `res/raw/keep.xml` сохраняет `ic_notification` при шринкинге; ошибка
  инициализации плагина ловится в форме и показывается снекбаром.
- Release-подпись читается из `android/key.properties`; при его отсутствии
  используется debug-ключ с предупреждением. Скрипты генерации keystore,
  split-сборки и `apksigner`-проверки добавлены.
- `LocalTimeZone` заменяет молчаливый UTC: IANA → алиасы `GMT`/`UTC` →
  фиксированное смещение устройства.
- Отметка показывает «Выполнено. Серия: N» с «Отменить» на 5 секунд;
  снятие — «Отметка снята».
- Обновлены текст политики, семантика выбранной темы, label «Привыкай»,
  adaptive icon и публичный URL политики (константа `AppInfo.privacyPolicyUrl`).
- `scripts/build_release_apk.ps1` собирает два ARM split-APK (16,1 и 18,4 МБ)
  и проверяет `ic_notification`, label, icon, permissions и manifest
  напоминаний.
