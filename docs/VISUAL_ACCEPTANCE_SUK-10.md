# SUK-10. Визуальная приёмка MVP и финальные ассеты RuStore

**Дата:** 23 октября 2026
**Автор:** Дизайнер
**Проверено:** SUK-8 и SUK-9 в `done`, debug APK собирается.
**Источник требований:** `design/DESIGN_SPEC.md` v1.1 (SUK-4) и токены `design/tokens/design-tokens.json`.

## 1. Как проверяли

- Экраны отрисованы **из реальных виджетов приложения** (не из HTML-макетов): `AppShell`,
  `HabitsScreen`, `StatisticsScreen`, `HabitFormScreen`, `SettingsScreen` с демо-данными
  (5 привычек, серии 1–13 дней, разные эмодзи/цвета/расписания, напоминания).
- Размер — 360 × 800 dp, DPR 3 → 1080 × 2400 px. Тёмная тема — отдельные кадры.
- Шрифты: Roboto (тот же, что в APK) + системный Segoe UI Emoji; метрики текста проверены
  тестом (ширина «Сегодня» = 109,7 px, «Пить воду» = 78,2 px — не заглушка Ahem).
- Инструмент: `flutter test tool/suk10_screenshots_test.dart` → `design/store/app/*.png`.
- Скриншоты карточки RuStore собраны в `design/store/store-1…4-*.png` (1080 × 1920).
- Иконка пересобрана из `design/assets/app-icon.svg` и внедрена в APK
  (`node design/tools/render-icons.mjs`).
- `flutter test` — 72/72, `flutter analyze` — без замечаний, `flutter build apk --debug` — успешно.

**Ограничение:** в окружении нет устройства/эмулятора Android (нет system-image и emulator).
Поэтому кадры сняты off-screen из настоящего дерева виджетов, а не с экрана телефона; жесты,
системные шрифты Emoji и уведомления на устройстве не проверялись.

## 3. Отклонения

Приоритеты: **P0** — блокирует публикацию или вводит пользователя в заблуждение;
**P1** — заметное расхождение с дизайн-системой или WCAG AA; **P2** — полировка;
**P3** — можно после релиза.

```powershell

```
