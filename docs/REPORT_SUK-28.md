# Отчёт SUK-28: экран политики под редакцию 1.1, пересборка 1.1.1

Дата: 13 ноября 2026.
Сборка: `1.1.1+3`, release APK только ARM (arm64-v8a и armeabi-v7a).
Статус: экран политики синхронизирован с опубликованной редакцией 1.1, тесты
и анализ зелёные, оба APK пересобраны и подписаны ключом компании.
В RuStore ничего не загружалось, тексты карточки не менялись.

## Причина

Экран `lib/features/settings/presentation/screens/privacy_policy_screen.dart`
остался от 1.0.0 и утверждал «Все данные хранятся только на этом устройстве».
Публичная политика уже в редакции 1.1: экспорт/импорт JSON, виджет,
уведомления и системный backup Android. Экран противоречил опубликованному
документу.

## Что изменено

### `privacy_policy_screen.dart`

Краткая офлайн-версия редакции 1.1 вместо юридического объёма страницы:

| Раздел | Содержание |
| --- | --- |
| Баннер | приложение офлайн, данные на устройстве, копии — только файл экспорта по команде пользователя или системный backup Android |
| Какие данные хранятся | привычки, иконки, цвета, дни, время, история, серии, настройки, снимок для виджета |
| Где хранятся | локальная база в приватном хранилище, нет аккаунта/серверов/облака/рекламы/аналитики, нет `INTERNET` |
| Экспорт и импорт | JSON создаётся по команде, место выбирает пользователь, приложение файл никуда не отправляет; импорт читает только выбранный файл и заменяет данные после подтверждения |
| Виджет главного экрана | необязательный, показывает прогресс, серию и до трёх названий; виден тому, у кого доступ к разблокированному телефону |
| Уведомления | текст содержит название привычки и может быть виден на экране блокировки; как скрыть средствами Android |
| Системное резервное копирование | копию в аккаунт Google может сделать ОС, а не приложение; отключается в настройках телефона |
| Удаление данных | сброс и удаление приложения удаляют локальные данные; файл экспорта и системная копия — отдельно |
| Полная редакция | краткая версия; полная редакция 1.1 — по ссылке из карточки RuStore, URL из `AppInfo.privacyPolicyUrl` показан `SelectableText` |

Абсолютная формулировка убрана. Ссылка не открывается приложением: сетевых
запросов нет, `url_launcher` не добавлялся, разрешение `INTERNET` отсутствует —
адрес можно скопировать и открыть в браузере.

### `lib/app/app_info.dart`

- `privacyPolicyUrl` = `https://Bayanist36.github.io/privykai-privacy/privykai-privacy.html`;
- добавлен `privacyPolicyEdition = '1.1'` для подписи на экране;
- `version` уже `1.1.1`, `pubspec.yaml` — `1.1.1+3`; версию не поднимали.

### Тесты

Новый `test/features/settings/presentation/screens/privacy_policy_screen_test.dart`
(4 теста):

- `AppInfo.version` = `1.1.1`, редакция 1.1, точный URL политики;
- экран содержит разделы об экспорте/импорте, виджете, уведомлениях и
  системном backup;
- старые абсолютные формулировки («Все данные хранятся только…»,
  «не покидают устройство») отсутствуют;
- URL полной редакции выводится в `SelectableText`.

### Документация

- `docs/privacy/README.md`: снят устаревший пункт о том, что экран не
  обновлён; зафиксировано решение показывать URL без сетевых запросов.

## Ограничения

- Устройство/эмулятор не подключались: экран проверен widget-тестами
  (включая отсутствие overflow при сборке всех секций) и анализом; визуальный
  smoke на реальном Android — в рамках QA.
- Публичная страница политики не менялась и остаётся в редакции 1.1
  (в её шапке указана версия 1.1.0). Экран приложения соответствует
  редакции 1.1, патч 1.1.1 не меняет текст политики.
- В RuStore ничего не загружалось; загрузка и тексты карточки — за
  оркестратором после QA.
